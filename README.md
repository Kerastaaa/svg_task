# SVG Editor CLI

TypeScript command-line SVG editor for Lab1 Phase 1.

Current status: Day 2 complete. The CLI now supports init, canvas, create, tree, show, move, scale, and set. Command-based undo/redo begins on Day 3.

## 开始开发

```text
npm install
npm run cli
npm test
npm run build
```
架构文档见 `doc/README.md`。

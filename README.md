# SVG Editor CLI

TypeScript command-line SVG editor for Lab1 Phase 1.

Current status: Day 3 complete. The CLI supports structural editing commands and command-based undo/redo. SVG read/save remains planned for Day 4.

## 开始开发

```text
npm install
npm run cli
npm test
npm run build
```
架构文档见 `doc/README.md`。
